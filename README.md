# eduplace

Eduplace is an API that provides CRUD operations for managing place reservations, such as classrooms, auditoriums, and labs.

* `Place` is the main class, while `Classroom`, `Auditorium`, and `Lab` are subclasses, each with its own rules.
* Not everyone can reserve every type of place. For example, a lab can only be reserved by professors.
